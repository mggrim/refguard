01 / 04   THE MANUSCRIPT

Every reference starts as a line of text.

You typed it, a co-author sent it, or a model made it up. On the page they all look the same.

02 / 04   THE PARSE

The parser separates each one into five fields.

Title, authors, year, venue and DOI, pulled out by fixed rules. No model reads the manuscript.

03 / 04   THE REGISTRY

Every field is compared with the scholarly record.

Crossref and the DOI registry answer three questions. Does the paper exist? Does each field belong to it? Has it been retracted? Books go to Open Library instead, because article registries index journals and the monographs you cite mostly predate DOIs.

04 / 04   THE VERDICT

Every verdict rests on evidence.

If a registry cannot be reached, the answer is “cannot certify”, never a pass. A reference is called fabricated only when both registries return 404. Anything unclear goes to review.

Eight verdicts in three tiers.

Fail-closed means an uncertain reference is sent back to you to check by hand rather than passed. A reference the registries do not recognise never passes.

Fabricated candidate
Blocking. Both Crossref and doi.org return 404 for the DOI.
Inconsistent
Blocking. The paper exists, but the title, authors, year, venue or DOI do not match it. References that mix fields from two papers land here.
Retracted
Blocking. The registry marks the paper as retracted.
Benign drift
Review. The reference differs only in formatting, or because the online-first and print versions carry different details.
Unverified
Review. Neither registry found the reference. That is not proof of fabrication, so check it by hand. Books are checked against Open Library. Theses, reports and trade press are indexed nowhere, and the report says so rather than leaving you guessing.
Ambiguous match
Review. A record was found, but the title is too general to identify a work and no author matches. Probably a different work with the same name rather than an error in your reference.
Registry unreachable
Review. A network problem stopped the check, so the reference cannot be certified.
Consistent
Pass. Every field matches the registry record.

Check a bibliography

RefGuard checks whether each reference accurately describes a real paper. It cannot judge whether that paper is the right one to cite. It draws on verification work by Katie Apker, Pedro Sant’Anna, Scott Cunningham, and Dhuliawala et al. (2023, Chain-of-Verification). Registry data comes from Crossref, which publishes the Retraction Watch database, from Open Library for books, and from doi.org.
